## Known Current Limitations

- M4 can publish and record a processing receipt. It does not provide exactly-once delivery, broker high availability, or zero data loss if the single broker disk fails.
- Replay, analytics, and the frontend remain unimplemented.
- The owner reported that the M2 and M3 GitHub Actions runs passed. This agent did not independently verify them. Remote M4 CI has not run until the user pushes this milestone.
- The preserved development database still has pending outbox rows. Leave `OUTBOX_PUBLISHER_ENABLED` false unless those rows should be published.
- Local Compose uses placeholder development credentials, not production secrets.
- Flyway metadata lookup warns on nonfatal HTTP 401 responses from repositories declared by `flyway-parent` 12.4.0. No CVE scan has been run.
- Architecture descriptions still include planned later-milestone behavior.

## Review Practice

When an item is resolved, retain its history or supersede it with a decision record; do not silently delete risk context. New approved architecture decisions require their own review rather than being implied by edits to this register.
