## What M7 implements

- A React 19 / TypeScript / Vite application in `frontend/`
- Device listing, registration, overview, three measurement charts, and keyset readings
- An in-memory device-admin key and same-origin `/api` and `/actuator` proxies
- Simulator `--clock now`, which stays inside the previous six UTC hours
- Images for the API, Worker, simulator, and web UI
- Disposable Compose project `streamforge-m7demo`
- Frontend CI and demo CI workflows, leaving Backend CI in place

## Four owner revisions

1. **Rolling windows.** Last 24 hours, Last 7 days, and Last 30 days are derived from one clock value per refresh. Summary and series share that `from` and `to`. A custom range stays fixed. Polling is 15 seconds and pauses while the document is hidden.
2. **Simulator clock.** `--clock now` does not emit a future `occurredAt`. The default deterministic clock is unchanged. Each live run needs its own seed because a later anchor changes the canonical hash.
3. **Numbers.** Display formatting uses JavaScript `Number`. It does not claim that `JSON.parse` preserves trailing zeroes. Null stays an em dash. Aggregates are not recomputed in the browser.
4. **Isolation.** The admin key is memory-only. PostgreSQL and Kafka are not published by the demo Compose file. Web and API host bindings are `127.0.0.1`. Playwright does not record traces, video, or screenshots.

## Local-only access

The operator types `DEVICE_ADMIN_API_KEY` into the dashboard. Refresh and Sign out clear it. The ingestion key is never sent to the browser. This is not an approved public sign-in. M8 has to design that before any public deployment.

Accepted telemetry, pending publication, and processing receipts are different counts. The overview states that they are not one funnel. A closed window can still change when a late event arrives.

## Demo

Generate keys into the gitignored `infra/.env.demo`. See [Development](../development.md). Open `http://127.0.0.1:4173`. Register or select a device, then run the simulator with `--clock now` and a new `--seed`. Stopping the demo without deleting volumes is `docker compose ... stop`. Deleting demo data is an explicit `down -v` of project `streamforge-m7demo` only.

Do not run that command against project `streamforge`. Do not enable the publisher on the preserved database.

## Verification boundary

Local Maven, frontend, image, Compose, and Playwright results belong in the implementation report. A green local run does not mark the remote workflows passed.
